# Add your first portfolio

Goal: create a real portfolio (beyond the virtual **All Portfolios** view) and understand scope.

## Steps

1. Start the app: `make dev` → http://127.0.0.1:5173
2. Open **Settings** → **Portfolios**
3. Click **Create portfolio** — name, base currency, optional description
4. Use the header **Portfolio view** selector to switch to your new portfolio

## Rules

- Max **5** active portfolios (including Default)
- **Default Portfolio** cannot be deactivated
- **All Portfolios** is virtual — not assignable as a transaction target

## Assign existing transactions (optional)

On **Transactions**, select rows and use bulk assign to move them into the new portfolio.
