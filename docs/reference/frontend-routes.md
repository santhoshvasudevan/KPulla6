# Frontend routes

Main React routes (see `frontend/src/App.jsx`):

| Path | Page |
|------|------|
| `/` | Dashboard |
| `/transactions` | Transactions |
| `/holdings` | Holdings |
| `/fixed-deposits` | Fixed Deposits |
| `/settings` | Settings |

Auth-gated — unauthenticated users redirect to login.
