# 006 — FX-1: Same-portfolio FX conversion legs

**ID:** FX-1  
**Branch:** `agent/006-fx-1`  
**Depends on:** 005 (recommended — cash surfaces stable)

## Goal

Implement **same-portfolio FX conversion** between cash currencies (Cash-8C partial): `FX_CONVERSION_OUT` / `FX_CONVERSION_IN` ledger entries linked via `CashTransferGroup` on a **single portfolio**.

## Scope

- `POST /api/v1/cash/fx-conversions` (or extend `/cash/transfers` with `type=fx_conversion` if planner prefers single endpoint)
  - User-entered `source_currency`, `target_currency`, `source_amount`, `target_amount` (or `user_rate`), `date`, `portfolio_id`
  - Creates `CashTransferGroup` + paired `CashLedgerEntry` rows; same portfolio for both legs
  - Validates sufficient source-currency cash; no implicit FX rate from server
- Update `cash/services.py`, serializers, scope validation
- Frontend: FX conversion form on Cash page (modal or section)
- Document in `docs/cash-ledger.md` (Cash-8C), `docs/api-design.md`
- Tests: conversion sufficiency, ledger signs, balance updates, TWROR internal-flow classification

## Do not implement

- Transfer fees (remain deferred within Cash-8C)
- Cross-portfolio FX (already Cash-8B)
- Bank ledger (`CashMovement`) FX
- Live FX rate fetch on conversion submit
