# Metric Sheet

The **Metric Sheet** (formerly “tear-sheet” in older docs) is the portfolio quantitative statistics panel on the dashboard.

## Contents

Risk/return statistics for the selected portfolio scope and date range — served by backend analytics, displayed read-only in React.

## Naming

Use **Metric Sheet** in UI copy and new docs. Historical files may still say “tear-sheet” — treat as legacy terminology.
